# Filtro HTML — Tienda de ropa

Maqueta de una tienda de ropa en **HTML y CSS**, desarrollada como prueba (filtro) del módulo.

## Páginas

- `index.html` — página de inicio.
- `abrigos.html`, `camisetas.html`, `pantalones.html` — catálogo por categoría.
- `carrito.html` — carrito de compras.

Cada página tiene su propia hoja de estilos.

## Ejecutar

Abre `index.html` en el navegador; no requiere dependencias.

## Stack

`HTML5` · `CSS3`
